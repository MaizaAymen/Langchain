# 🍝 Meal Generator AI 🍱

This is a simple command-line tool that uses **LangChain** and **Groq's LLM (LLaMA3)** to generate a list of meal titles for a specified cuisine.
![image](https://github.com/user-attachments/assets/c9bc55ee-884c-43a5-97f4-b0f030434ddf)

## 📦 Features

- Uses **Groq's LLaMA3-70B** language model via `langchain_groq`
- Generates a list of **n cooking/meal titles** for a given cuisine
- CLI-based interaction
